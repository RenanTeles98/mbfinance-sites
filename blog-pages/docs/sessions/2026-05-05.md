## Analytics multisite

### Resumo

Corrigido o carregamento de dados do GA4 no painel e adicionada base para visualizar metricas de outros sites da empresa no mesmo painel.

### Problemas encontrados e solucoes

- O frontend de analytics usava `mb_site_domain` para montar `/api/analytics/overview`. Quando esse valor aponta para o dominio publico do site, a rota do app Next pode nao existir ali, quebrando os dados da MB Finance.
- A chamada agora usa a base da API do painel (`getApiBase`) e envia o site selecionado por `?site=`.
- O backend agora resolve configuracao GA4 por chave de site e retorna uma lista de sites para montar o seletor.

### Decisoes tomadas

- Manter um unico endpoint de analytics com parametro `site`.
- Preservar compatibilidade com `GA4_PROPERTY_ID`, `GA4_CLIENT_EMAIL` e `GA4_PRIVATE_KEY` para a MB Finance.
- Preparar `mb-negocios` e `fomenta` sem exigir que os IDs reais sejam versionados no codigo.

### Validacao

- `npm run build` executado com sucesso.
- Permanecem apenas avisos ja existentes sobre uso de `<img>` em vez de `next/image`.

### Proximos passos

- Adicionar as propriedades GA4 reais de MB Negocios e Fomenta na Vercel.
- Garantir que a service account tenha permissao de leitura em cada propriedade GA4.
