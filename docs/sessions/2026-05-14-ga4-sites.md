# Sessao 2026-05-14 - GA4 por site no admin

## Resumo

- Investigado o aviso "MB Negocios (configurar GA4)" no seletor do painel.
- Corrigido o backend para respeitar o site selecionado nas APIs de analytics e campanhas.
- Documentado o uso de Property ID separado por site com fallback para a service account principal.

## Arquivos alterados

- `blog-pages/lib/ga4.ts`
- `blog-pages/app/api/analytics/overview/route.ts`
- `blog-pages/app/api/analytics/campaigns/route.ts`
- `blog-pages/.env.example`
- `CONTEXT.md`
- `DECISIONS.md`
- `TODO.md`
- `CHANGELOG.md`

## Problemas encontrados e solucoes

- O frontend ja tinha os sites MB Finance, MB Negocios e Fomenta, mas a API consultava sempre o GA4 principal.
- A rota `/api/analytics/overview` nao lia `?site=...`, entao MB Negocios podia continuar mostrando dados da MB Finance.
- A solucao foi criar resolucao de configuracao por site no `lib/ga4.ts`, retornando tambem o status real de cada site para o seletor.

## Validacao

- `npm run build` em `blog-pages/` executado com sucesso.
- Restaram apenas avisos preexistentes do Next.js sobre uso de `<img>`.
